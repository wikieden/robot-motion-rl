第 15 章 · MPPI：撒一把随机序列，按 exp(−代价/λ) 加权平均

配套讲义：第 15 章 · iLQR 与 MPPI：不训练策略，每次现算一条轨迹 第三步。系统 x' = x + 0.1·(sin x + u)，从 0 走到 π，30 步，代价 Σ(x − π)² + 0.1u²，和讲义一致；页面里的随机数和代码不同，收敛曲线只是同一个过程的另一次运行。
缩写：MPPI = Model Predictive Path Integral（模型预测 / 路径 / 积分）；λ：温度，越小越只听最好的那几条；iLQR = iterative LQR（迭代 / LQR）。
