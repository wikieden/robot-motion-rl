跑起来看

在文件面板里点开 html 只是静态快照，按钮和滑块不动。用本地服务打开：.claude/launch.json 里的 robot-motion-rl-animations，或者在仓库根目录：

python3 -m http.server 8354 --directory robot-motion-rl/notes/animations

然后浏览器打开 http://localhost:8354/01-pd-layers.html。

新增或修改一个动画

  1. 页面引用 anim.css 和 anim.js（与其他专题同一套），提供 reset(seed) 和 next()（返回 false 表示播完），用 setupPlayer({captureSeed, reset, next}, 毫秒) 挂上播放按钮。随机数一律用 rnd() / gauss()，录制结果可复现。
  2. 重新录 GIF（在本目录下执行）：

bash node ../../../tools/anim-capture/capture.mjs 01-pd-layers.html 01-pd-layers.gif 90

  1. 新增或改名后，在仓库根目录跑 python3 tools/gallery/build.py 更新画廊。
