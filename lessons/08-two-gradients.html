第 8 章 · 两种梯度：「试了打分」的似然比梯度 vs 「顺着公式求导」的解析梯度

对应原文：SuperMimic §3.3（papers/supermimic-2610.28480.txt L278–L281：PPO 是 likelihood-ratio 估计，BPTT 对每个动作求导，短视野内方差低得多）、§4.2「First-order gradients need fewer imagined steps」（L440–L442）；《从零学强化学习》第 20 章策略梯度、第 21 章 baseline
本章缩写：score function：得分函数，\(\nabla_\theta\log\pi\)（第 20 章）；pathwise gradient：路径梯度 / 解析梯度（沿着「参数 → 动作 → 回报」这条计算路径求导）；ε：标准正态噪声（读 "epsilon"）；PPO-WM：在 world model 里跑的 PPO（WM = World Model）。全部缩写见 附录 · 缩写与术语表

讲解

第一步：同一个问题，两种算法（2026-11-20）

类比：调咖啡里的糖。 办法一：放不同量的糖各冲几杯，尝一尝打分，看「多放糖的那几杯分高不高」，猜出该多放还是少放。办法二：你知道甜度和糖量的公式，直接求导，知道「多放 1 克，甜度变多少」。

玩具问题（编的，整章都用）：回报 \(J(a) = -(a-2)^2\)（动作越接近 2 越好）。策略是高斯：\(a = \theta + \sigma\varepsilon\)，\(\varepsilon \sim \mathcal N(0,1)\)，σ = 0.5。在 θ = 0 处求平均回报对 θ 的梯度。

真值：$\frac{d}{d\theta}\mathbb E[J] = \mathbb E[J'(a)] = -2(\theta - 2) = $ 4（往大调 θ）。

一句话：同样求「θ 往哪调」，一种靠试和打分，一种靠求导。

第二步：似然比梯度（PPO 用的）（2026-11-20）

第 20 章的策略梯度：

\[\nabla_\theta \mathbb E[J] = \mathbb E\big[(J(a) - b)\,\nabla_\theta\log\pi(a)\big]\]

高斯策略下 \(\nabla_\theta\log\pi(a) = (a-\theta)/\sigma^2 = \varepsilon/\sigma\)，所以

\[\hat g_{LR} = \frac1N\sum_i (J(a_i) - b)\,\frac{\varepsilon_i}{\sigma}\]

每个样本只贡献一个标量分数 \(J(a_i)\)，方向全靠「分高的样本噪声往哪边偏」去猜。b 是 baseline（第 21 章），这里取这批的平均分。不需要知道 J 的公式，环境是黑箱。

例子：4 个样本 ε = [0.5, −1.0, 1.5, 0.2]，a = θ + 0.5ε = [0.25, −0.5, 0.75, 0.1]：

1 2 3 4
J(a) −3.06 −6.25 −1.56 −3.61
J − 平均（−3.62） +0.56 −2.63 +2.06 +0.01
× ε/σ +0.56 +5.26 +6.18 +0.00

平均 ≈ 3.0，真值是 4。

一句话：似然比梯度只看分数，不看公式，所以能用在黑箱上，但每个样本带回的信息少。

第三步：解析梯度（SuperMimic 用的）（2026-11-20）

如果 J 可导，把 \(a = \theta + \sigma\varepsilon\) 代进去，沿路径求导：\(\frac{dJ}{d\theta} = J'(a)\cdot\frac{da}{d\theta} = J'(a)\cdot 1\)，

\[\hat g_{PW} = \frac1N\sum_i J'(a_i) = \frac1N\sum_i -2(a_i - 2)\]

每个样本直接带回一个方向（导数），不用靠一批样本互相比较。

例子（同样 4 个样本）：J'(a) = [3.5, 5.0, 2.5, 3.8]，平均 = 3.7。

代价：必须知道 J（以及 J 里面的环境动态）怎么随动作变，也就是环境要可微。真实仿真器的接触是突变的、实现也不一定支持求导，所以 SuperMimic 学了一个可微的替代模型（第 9 章）。

一句话：解析梯度要可微的环境，换来每个样本都带方向。

第四步：重复 2000 次看散布（2026-11-20）

一次估计看不出好坏，重复 2000 次（每次 N 个样本），看平均和标准差：

N 似然比（平均 ± 标准差） 解析（平均 ± 标准差）
4 2.99 ± 2.46 4.00 ± 0.51
64 3.95 ± 0.71 4.00 ± 0.13
  • 同样 4 个样本，似然比的散布是解析的约 5 倍；要把似然比压到差不多，得多用好几倍样本。
  • PPO 在机器人上用 98304 个样本一批（第 3 章），就是在用样本量压方差。

SuperMimic 的机制消融（L440–L442、图 5b）把这一点放在真实问题上：在同一个 world model 里跑 PPO（PPO-WM），SuperMimic 达到 PPO-WM 的最好回报只用了约 1/64 的想象步数。模型一样、仿真速度一样，差别只在梯度类型。

一句话：解析梯度方差小得多，同一个模型里比 PPO 省约 64 倍样本。

数学原理

  • log 导数技巧：\(\nabla_\theta\mathbb E_{a\sim\pi_\theta}[J(a)] = \mathbb E[J(a)\nabla_\theta\log\pi_\theta(a)]\)，第 20 章推过。
  • 重参数化：把随机性搬到与 θ 无关的 ε 上（\(a = \theta + \sigma\varepsilon\)），期望和导数就能交换：\(\nabla_\theta\mathbb E_\varepsilon[J(\theta+\sigma\varepsilon)] = \mathbb E_\varepsilon[J'(\theta+\sigma\varepsilon)]\)。VAE 用的是同一个技巧。
  • 方差与样本数：独立样本平均的标准差按 \(1/\sqrt N\) 下降：N 从 4 到 64，标准差约降为 1/4。

公式清单

公式 意思
\(\hat g_{LR} = \frac1N\sum (J(a_i)-b)\,\varepsilon_i/\sigma\) 似然比（score function）估计
\(\hat g_{PW} = \frac1N\sum J'(a_i)\,\frac{da}{d\theta}\) 解析（pathwise）估计
\(a = \theta + \sigma\varepsilon\) 重参数化

讲义 ↔ 代码（玩具回报和样本是编的，重复实验用固定随机种子 0）：

讲义 公式 写法 跑出来
第一步 真值 −2(θ − 2) dJ_da(0.0) 4.0
第二步 似然比 mean[(J − b)ε/σ] score_estimate(0, 0.5, eps) 2.999
第三步 解析 mean[J'(a)] pathwise_estimate(0, 0.5, eps) 3.700
第四步 散布 重复 2000 次 spread(..., n) N=4：2.99 ± 2.46 vs 4.00 ± 0.51

关键几行：

a = theta + sigma * eps                          # 重参数化：随机性都在 eps 里
g_lr = np.mean((J(a) - J(a).mean()) * eps / sigma)   # 似然比：只用分数 J(a)
g_pw = np.mean(dJ_da(a))                         # 解析：沿 a 对 θ 求导（da/dθ = 1）

代码里才看得到的 2 件事：

  • 似然比估计在 N = 4 时平均只有 2.99，不是 4：baseline 用了同一批样本自己的平均，会带来 (N − 1)/N 的缩小（4 × 3/4 = 3）。N = 64 时这个偏差变成 63/64，平均回到 3.95。实际实现里 baseline 用 critic 或「留一法」平均，就没有这个偏差。
  • 解析梯度的散布只来自 ε 本身（J' 是 a 的一次函数），所以 N = 4 时标准差 = 2σ/√4 = 0.5，和跑出来的 0.51 一致。
