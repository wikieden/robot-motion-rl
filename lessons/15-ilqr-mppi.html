第 15 章 · iLQR 与 MPPI：不训练策略，每次现算一条轨迹

本章缩写：iLQR = iterative LQR（迭代 / LQR）；DDP = Differential Dynamic Programming（微分 / 动态 / 规划）；MPPI = Model Predictive Path Integral（模型预测 / 路径 / 积分）；λ：MPPI 的温度参数（读 "lambda"；论文 L147 叫它 inverse temperature，但在 exp(−S/λ) 里它起的是温度的作用：越大权重越平均）；S_k：第 k 条采样序列的总代价；α：线搜索步长（读 "alpha"）。全部缩写见 附录 · 缩写与术语表

讲解

第一步：轨迹优化：直接求一串控制量（2026-11-20）

类比：出门前在地图上规划路线，而不是练一套「看到哪个路口就怎么拐」的本能。

RL 学的是策略（任何状态下该怎么做）；轨迹优化求的是一条轨迹（从当前状态出发，接下来 T 步的控制序列 \(u_0, \dots, u_{T-1}\)）。

例子（编的，整章都用）：\(x_{t+1} = x_t + 0.1\,(\sin x_t + u_t)\)，从 x = 0 走到 x = π（像把摆从下面甩到上面），代价 \(\sum_t (x_t - \pi)^2 + 0.1\,u_t^2\)，T = 30。什么都不做（u 全 0）时，x 一直停在 0，代价 296.1。

一句话：不学策略，直接为眼前这一次求一串最好的控制量。

第二步：iLQR：沿着当前轨迹线性化，用 LQR 修一修（2026-11-20）

类比：照着一张草图描，每描一遍就修正一点，几遍后就准了。

第 12 章的 LQR 只在一个平衡点附近线性化。iLQR 沿整条当前轨迹逐点线性化（原文 L174–L176）：

  1. 按当前控制序列往前滚，得到轨迹 \(x_0, \dots, x_T\)；
  2. 在每个点上算 \(a_t = \partial f/\partial x\)、\(b_t = \partial f/\partial u\)，把代价展开到二次；
  3. 从最后一步往前做一遍 LQR（Riccati 反推），得到每一步的修正：\(\delta u_t = k_t + K_t\,\delta x_t\)；
  4. 带着修正往前滚（如果代价没降就把步长 α 减半），回到 1。

例子：每次迭代后的总代价

迭代 0 1 2 3 4 以后
代价 296.09 39.04 23.76 23.73 23.73

3 次就收敛，最后 x = 3.141。iLQR 用的是导数：它相当于第 8 章的解析梯度，只是还用了二阶信息，所以收敛很快。DDP 再多保留动力学的二阶项（L178）。

一句话：iLQR = 沿轨迹线性化 + LQR 反推 + 往前滚，几次就收敛。

第三步：MPPI：撒一把随机序列，按代价加权平均（2026-11-20）

类比：派 64 个探子各走一条略有不同的路，走得好的人说话分量大，大家的意见加权平均成下一版路线。

MPPI 不求导数：

  1. 在当前控制序列上加高斯噪声，得到 K 条候选序列 \(u + \varepsilon_k\)；
  2. 每条往前滚、算总代价 \(S_k\)；
  3. 权重 \(w_k \propto \exp\big(-(S_k - \min S)/\lambda\big)\)，归一化；
  4. 更新 \(u \leftarrow u + \sum_k w_k\,\varepsilon_k\)。

例子：4 条序列的代价 [10, 12, 20, 11]：

λ 权重
1 [0.665, 0.090, 0.000, 0.245]
5 [0.381, 0.255, 0.052, 0.312]

λ 小 → 几乎只听最好的那条；λ 大 → 大家平均。这个 exp 加权和第 5 章的 softmax 是同一个东西，背后是重要性采样（原文 §C，L343）。

同一个甩摆问题（64 条、σ = 1、λ = 1），每轮代价：296.1 → 101.7 → 56.1 → 41.3 → … → 25.0（8 轮）。比 iLQR 慢，也没到 23.73，但完全不用导数，而且 64 条可以在 GPU 上同时滚。

一句话：MPPI = 撒随机序列 + exp(−代价/λ) 加权平均，不要导数，好并行。

第四步：放回全书：在线优化 vs 离线策略（2026-11-20）

iLQR MPPI RL（PPO / SuperMimic）
要模型 要，还要导数 要，只要能往前滚 PPO 不要；SuperMimic 要学一个
梯度类型（第 8 章） 解析（加二阶） 采样（和似然比同类） PPO 采样；SuperMimic 解析
什么时候算 每一刻在线算 每一刻在线算 离线训练，部署时一次前向
接触、突变 导数难用 能处理 能处理

用在机器人上时，iLQR / MPPI 通常做成 MPC：每个周期从当前状态解一次、只执行第一步（第 14 章）。RL 可以看成「把无数次在线优化的结果，离线压进一个网络」。

一句话：iLQR 和 MPPI 是在线现算，RL 是离线学好；梯度类型的取舍和第 8 章一模一样。

数学原理

  • 局部二次近似：在当前轨迹附近把动力学线性化、代价展开到二次，就能套 LQR 的闭式解。
  • 线搜索：沿修正方向先试整步（α = 1），代价不降就减半，保证每次迭代代价单调下降。
  • 重要性采样：用 exp(−S/λ) 给样本加权，相当于从「代价低的轨迹更可能」的分布里估计最优控制。

公式清单

公式 意思
\(a_t = \partial f/\partial x,\ b_t = \partial f/\partial u\) 沿轨迹线性化
\(\delta u_t = k_t + K_t\delta x_t\) iLQR 的修正（前馈 + 反馈）
\(w_k = \frac{\exp(-(S_k-\min S)/\lambda)}{\sum_j \exp(-(S_j-\min S)/\lambda)}\) MPPI 权重
\(u \leftarrow u + \sum_k w_k\varepsilon_k\) MPPI 更新

讲义 公式 写法 跑出来
第一步 不控制 总代价 total_cost(rollout(0, zeros), zeros) 296.09
第二步 iLQR 反推 + 正推 ilqr() 296.09 → 39.04 → 23.76 → 23.73；末端 x = 3.141
第三步 权重 exp(−ΔS/λ) mppi_weights([10, 12, 20, 11], λ) λ=1：[0.665, 0.09, 0, 0.245]
第三步 MPPI 8 轮 mppi() 296.1 → … → 25.0

关键几行：

a, b = 1 + DT * np.cos(xs[t]), DT              # 沿当前轨迹线性化
ks[t], kk[t] = -qu / quu, -qux / quu           # LQR 反推：前馈 k、反馈 K
un[t] = us[t] + alpha * ks[t] + kk[t] * (xn[-1] - xs[t])   # 带修正往前滚
w = np.exp(-(s - s.min()) / lam); w /= w.sum() # MPPI：按代价加权
us = us + w @ eps                              # 加权平均噪声来更新

代码里才看得到的 2 件事：

  • iLQR 的反推里，第 t 步的状态代价算在 \(x_{t+1}\) 上，所以要通过 a、b 折回到 \((x_t, u_t)\)；这是代码里 lx、qx、qu 那几行的来源。
  • MPPI 的权重先减去最小代价再取 exp，防止 exp(−296) 下溢成 0；这不改变归一化后的权重。
